# Argilla 2.8.0: виправлення клавіш `1/2/3`

Привіт! Передаю патч для втрати гарячих клавіш після кліку по фону або тексту на сторінці розмітки. Баг відтворюється на тому самому записі, без переходу до наступного.

Причина — втрата фокуса контейнером варіантів. Патч відновлює фокус поточного запитання після кліку по неінтерактивній області, зберігає виділення тексту й не перехоплює цифри в полях введення, меню та модалках. Зміни лише у чотирьох Vue-компонентах; бекенд, збереження та auto-submit не змінював.

- База: чиста `v2.8.0`, SHA `78cb5183`.
- Патч: [annotation-shortcuts-v2.8.0.patch](./patches/annotation-shortcuts-v2.8.0.patch), усі зміни виправлення одним diff.
- Перевірки: 510 Jest PASS, Chromium/WebKit, 50 повторних кліків на одному записі та черга з 10 тестових записів. Локально також перевірив вручну.
- Обмеження: Firefox 132 блокується помилкою `CSS.highlights` у базовій версії. Production-збірку та робочий сервер не перевіряв.

Звір, будь ласка, патч із робочою збіркою та перевір на staging перед впровадженням.

[Код і тести на GitHub](https://github.com/FIOWB21/argilla/tree/fix/annotation-shortcuts-click-away). Деталі перевірок: [PROGRESS.md](./PROGRESS.md), [TEST_PLAN.md](./TEST_PLAN.md).
