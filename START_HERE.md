# START_HERE.md — Argilla 2.8.0: исправление shortcuts после клика вне ответов

## Кратко о задаче

**Что сломано:** во время разметки работают цифровые shortcuts `1/2/3`, но после клика мышью по фону, по тексту записи или иному **неинтерактивному** участку страницы перестают работать. Клик по странице не восстанавливает их; клик **по варианту ответа** восстанавливает. Ошибка воспроизводится **на одной и той же записи**, без смены текста или перехода между записями.

**Что нужно:** цифровые shortcuts должны работать после таких кликов, если пользователь по-прежнему находится в режиме разметки. В полях ввода, модалках, меню и других активных контролах существующие действия клавиатуры должны сохраняться.

**Вне задачи:** подмена/«проскок» текста, предзагрузка и порядок записей; мы их не диагностируем и не исправляем.

## Что сделать в самом начале

1. Распакуй архив. Открой `docs/GITHUB_SETUP.md` — агент должен **первым делом** помочь настроить GitHub и кнопку VS Code **Sync Changes**, а также сохранить базовую версию для отката.
2. Открой в VS Code локальный репозиторий **исходников Argilla** (не корпоративную страницу в браузере). Если его нет — агент поможет клонировать безопасную базу `v2.8.0`.
3. Скопируй `AGENTS.md`, `START_HERE.md` и папку `docs/` в корень репозитория. При совпадении с существующими документами — сначала объединить/сделать backup, **не перезаписывать чужие файлы автоматически**.
4. Передай агенту **первое сообщение**:

> Прочитай AGENTS.md, START_HERE.md, docs/TASK.md, docs/STEPS.md, docs/PROGRESS.md, docs/GITHUB_SETUP.md и docs/TEST_PLAN.md. Сначала помоги настроить GitHub, локальный Git и кнопку Sync Changes в VS Code; создай точку отката и отдельную рабочую ветку. Первым ответом покажи план и инструкцию для моего участия в настройке. Затем работай по STEPS.md, фиксируй всё в PROGRESS.md и коммитах. Задача — только потеря shortcuts 1/2/3 после клика по неинтерактивной области страницы Argilla, БЕЗ смены записи. Не анализируй скачки/подмену текстов, не трогай backend и production.

## Следующий сеанс с другим агентом

> Прочитай AGENTS.md, docs/PROGRESS.md, docs/STEPS.md. Проверь состояние Git и продолжи ближайший незавершённый этап. Перед началом дай план. После этапа обнови PROGRESS.md, перечисли реальные тесты, SHA и следующий шаг. Не выходи за scope клика вне вариантов ответа.

- `AGENTS.md` — постоянные ограничения и инструкция для агента.
- `docs/TASK.md` — техническое задание, кодовые ориентиры и критерии приёмки.
- `docs/STEPS.md` — порядок выполнения.
- `docs/PROGRESS.md` — журнал, который обновляется после каждого этапа.
- `docs/GITHUB_SETUP.md` — GitHub/VS Code: Clone, Commit, Sync, rollback.
- `docs/TEST_PLAN.md` — основной тест клика вне ответа и регрессии.
- `docs/DEPLOYMENT.md` — безопасная передача фикса администратору компании.
